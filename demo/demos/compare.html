The same task, twice: by an ordinary agent, and by mint.

Both halves below are real and both start from the same page in the same browser. On the left, a model decides every step, the way almost every agent works today. On the right, the same task runs as a compiled skill. Nothing is slowed down to make one look better, and the difference is not the clock — it is what each of them pays, and what each of them can prove afterwards.

      What the two halves actually change

      1 · the bill

      It stops growing with use.

      The ordinary agent asks a model for every decision, on this run and on the next one and on every one after that. mint asked once, when the task was learned, and asked zero times in the run you just watched. Ten thousand runs of this task is ten thousand times as many questions on the left, and the same none on the right — because the right-hand cost is reading a page, not buying a judgement.

      2 · the path

      It stops moving, which is what makes approving it possible.

      A model's answer is sampled, so two ordinary runs on the same page can take different routes and touch different things — you cannot approve a procedure that will not do the same thing tomorrow. A compiled step is the same program every time. That is what turns "an agent may do this" into something a person can actually agree to.

      It stops moving until the page changes. Then that one step stops, and asks, or refuses. It does not guess.

      3 · the record

      There is something to hand to somebody else.

      The right-hand half leaves a signed receipt for every decision, written before the action it describes, chained so a missing one shows, and checkable by whoever receives it without asking us. The left-hand half leaves a transcript of what it says it did. The difference is not the existence of logs; it is whether anybody but the author can rely on them.

      4 · what this costs

      The first run is not free, and this is the entire source of the saving.

      Learning this task cost three or four questions to a model and about three seconds, once. The saving afterwards is exactly that cost, paid on the first run instead of on every run — there is no second trick. And when mint meets a step it cannot recognise, it stops and asks about that one step, or refuses it: a mistake costs one question, never a broken run.

      what this does not show

      It does not show that mint is better at the task. Both halves reached the same page here, and on a page with no stable structure the ordinary agent is the one that copes and mint is the one that stops — that limitation is on every page of this site. It also does not compare against the best possible ordinary agent: the left-hand half is a straightforward model-in-the-loop driver, built from the same runtime so that both halves are measurably the same except for how the steps are decided.
