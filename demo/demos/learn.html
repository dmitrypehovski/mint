what this does not show

It does not show that the second run is free in general. It is free when the page still matches the shape the skill was compiled against; when it does not, the runtime stops, asks about that one step, and pays for that step. The claim is not zero cost — it is that a mistake costs one question rather than a broken run, and that the same question is not paid for twice.
