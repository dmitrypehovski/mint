Four elements, four kinds of decision

This page exists so the write gate can be exercised on real elements instead of described. Nothing here is a mock: each item below is the kind of thing a skill meets in the wild, and the gate has to say something honest about each one before it is touched.

navigation — changes nothing

Open the record

A link with somewhere to go. Reading it cannot alter anything on the far side.

input — does not commit

Typing into a field fills it. The commit, if there is one, is the submit.

write — commits something

Submit the filing

This is where the world changes. A gate that cannot stop here is not a gate.

unclassifiable — refused

An element that is neither

No destination, no button semantics. Nothing here can be described to a person, so nothing here can be approved, so it must be refused rather than attempted.
